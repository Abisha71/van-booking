# 🚐 PRATHEEP TOURS - Van Booking Website

A simple and modern van booking website built using HTML, CSS, and JavaScript.



## ✨ Features

- 📍 Enter Pickup & Drop locations  
- 👥 Select number of passengers  
- 🎉 Booking confirmation display  
- 🖼 Van image with modern UI  
- ✨ Smooth fade/slide animations  
- 💬 WhatsApp button for direct contact  

---

## 🌐 Live Website

👉 https://your-username.github.io/van-booking/



## 🛠 Technologies Used

- HTML5  
- CSS3  
- JavaScript  



## 📱 How to Use

1. Enter your **pickup location**  
2. Enter your **drop location**  
3. Enter **number of passengers**  
4. Click **Book Now**  
5. Contact via **WhatsApp button**  


## 📌 Notes

- This is a **frontend project only** (no backend/database).  
- Bookings are not stored — users contact via WhatsApp.  
- Fully responsive and works on mobile & desktop.
